# DevNepal design assets — provenance

These files are ported verbatim from the DevNepal frontend so gov-portal can
reuse its validated visual language:

- Source: https://github.com/voidash/DevNepal, branch `demo/minimal-validated-flow`
  (`static/src/*.css`, `static/vendor/primer/primer.css`, `static/fonts/*`, `static/images/*`)
- Primer CSS is vendored under its MIT license; the DevNepal tokens and
  component styles layer on top of it.
- Fonts: Inter and Barlow / Barlow Condensed (SIL Open Font License; see
  `static/fonts/inter-OFL.txt` in the source repository).
- The emblem of Nepal is a government asset used for the state strip.

Only design assets are ported — no Django application code.
