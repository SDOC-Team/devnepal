## यो के हो

devNepal नेपाल सरकारका प्रविधि परियोजनाहरूको सार्वजनिक सूची हो। सरकारी निकायहरूले सहयोग चाहिएको काम प्रकाशित गर्छन्; जो कोहीले योगदान गर्न सक्छन्। सबै काम सार्वजनिक रिपोजिटरीमा हुन्छ।

यो रिपोजिटरी आफैँमा यो पोर्टल हो — र यसमा सूचीबद्ध पहिलो परियोजना पनि यही हो।

**devNepal ले बनाएको पहिलो कुरा devNepal नै हो — पहिलो कमिटदेखि नै सार्वजनिक रूपमा।**

## नौ प्रकारका योगदान

कोड तीमध्ये एक मात्र हो। सबै नौवटा योगदानको समीक्षा तोकिएका मेन्टेनरले गर्छन् र समान रूपमा श्रेय दिइन्छ।

**कोड** · **डिजाइन र UX** · **पहुँचयोग्यता** · **नेपाली अनुवाद र सामग्री** · **दस्तावेजीकरण** · **परीक्षण र बग रिपोर्ट** · **सुरक्षा** · **अनुसन्धान** · **समुदाय सहयोग**

नेपाली त्रुटि सन्देश सुधार्नुभयो वा कन्ट्रास्टको समस्या फेला पार्नुभयो भने पनि तपाईंले योगदान गर्नुभयो। हामीलाई जानकारी दिनुहोस्, श्रेय दिनेछौं।

## स्थानीय रूपमा चलाउने तरिका

```bash
git clone https://github.com/SDOC-Team/devnepal.git
cd devnepal
cp .env.example .env
npm install
npm run dev
```

<http://localhost:3000> खोल्नुहोस्।

**नयाँ कम्प्युटरमा दस मिनेटभित्र यो नचलेमा त्यो बग हो — कृपया इस्यु खोल्नुहोस्।**
